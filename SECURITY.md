# Security Policy

## Supported branch

Security fixes target the default branch.

## Reporting a vulnerability

Use GitHub Private Vulnerability Reporting for this repository. Do not open a public issue containing exploit details, credentials, personal data, or production configuration.

Include:

- affected route or component;
- a minimal reproduction;
- expected and observed behavior;
- potential impact;
- any suggested mitigation.

## Public-demo boundary

The linked deployment is a technical portfolio demonstration. Do not upload confidential, regulated, or third-party personal data. Never commit production credentials or copy values from a local environment file into an issue.

## Repository controls

The default branch is expected to require CI and CodeQL checks. Secret scanning, push protection, dependency alerts, security updates, and private vulnerability reporting are enabled on the public repository.
